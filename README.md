### Before running the project

This analysis was performed with R version 4.5.3, using `renv` for package management to ensure consistent versioning.

Install `renv` with:

```r
install.packages("renv")
```

Open the project `traits_analysis.Rproj` in RStudio.

Set up the `renv` environment from within the project:

```r
# Inside the RStudio session
renv::restore()
```
